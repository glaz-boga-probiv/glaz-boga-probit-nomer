Начать с номера можно без имени. Ответ может подсказать имя, почту или аккаунт, когда есть совпадение. Затем уже проверяйте найденную зацепку отдельно.

Они могут происходить из разных контактных записей и периодов. Читайте их как подсказки, а не как единое официальное имя владельца.
